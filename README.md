# 🏗️ PredictFlow

Plateforme de prédiction de churn client — projet portfolio MLOps.

## Description
PredictFlow prédit si un client va résilier son abonnement (churn)
à partir de ses données comportementales.
Projet construit dans le cadre d'une formation Développeur IA (RNCP 37827).

## Dataset
Telco Customer Churn (Kaggle) — 7 043 clients, 21 colonnes

## Stack
- Python 3.11+
- (à compléter au fil des sprints)

## Installation
```bash
git clone https://github.com/kabweb712-hash/predictflow.git
cd predictflow
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```
